CPU와 GPU, DRAM과 HBM

  • 실험 1한 가지 일을 순서대로 할 때는 CPU가 빠르고, 같은 일을 잘게 나눠 한꺼번에 할 때는 GPU가 빠릅니다.
  • 실험 2CPU는 빠르지만 DRAM에서 데이터를 가져오는 데 오래 걸립니다. 그래서 CPU 안에 캐시를 층층이 둡니다.
  • 실험 3HBM은 DRAM 칩을 수직으로 쌓아 GPU 바로 옆에 붙이고 데이터 길을 크게 넓혀, 한 번에 훨씬 많은 데이터를 보냅니다.
  • 실험 4게임 로딩이 오래 걸리는 것은 데이터가 저장장치와 PCIe 같은 좁은 길을 지나 그래픽 메모리까지 옮겨져야 하기 때문입니다.

실험 2

데이터는 어디에 있나

CPU는 1초에 수십억 번 계산하지만, 메인보드에 꽂힌 DRAM에서 데이터를 받아 오려면 약 90 ns(1억분의 9초)를 기다려야 합니다. 그동안 CPU는 450번 계산할 수 있습니다. 그래서 자주 쓰는 데이터를 CPU 안의 작고 빠른 기억 장소, 캐시에 둡니다. 책을 찾는 일에 빗대어 보세요.

실험 3

넓은 길, HBM

GPU의 코어 1만 개가 쉬지 않으려면 데이터가 엄청나게 많이 필요합니다. HBM(High Bandwidth Memory)은 DRAM 칩을 8~12층으로 쌓고, 실리콘을 위아래로 뚫은 전극(TSV)으로 층을 이어, GPU 바로 옆에 붙인 메모리입니다. 데이터가 지나가는 길(핀)이 일반 DRAM보다 훨씬 많습니다.

DDR5 · 2채널
89.6 GB/s—
HBM3 · 4스택
약 3,277 GB/s—

▶ 1 GB 옮기기를 눌러 보세요.

DDR5 · 대역폭 = 길의 수 × 길 하나의 속도64비트 × 2채널 × 5.6 Gb/s ÷ 8 = 89.6 GB/s
메인보드 위 수 cm 거리, 칩을 옆으로 나란히 배치
HBM3 · 대역폭 = 길의 수 × 길 하나의 속도1,024비트 × 6.4 Gb/s ÷ 8 = 819 GB/s (스택 하나)
스택 4개면 약 3.3 TB/s · GPU 옆 수 mm 거리

핀 하나의 속도는 DDR5와 HBM3가 비슷합니다. HBM이 빠른 것은 길의 수가 스택 하나에 1,024개로 많기 때문입니다. 칩을 쌓고 TSV로 이어야 이렇게 많은 길을 좁은 면적에 낼 수 있습니다. 한 번에 보내는 양(대역폭)이 큰 것이지, 첫 데이터가 도착하는 시간(지연)이 짧아지는 것은 아닙니다.

실험 4

게임 로딩은 왜 오래 걸릴까

게임을 시작하면 지형, 텍스처, 3D 모델 같은 데이터가 저장장치에서 출발해 DDR5를 거치고, 그래픽카드가 꽂힌 PCIe 슬롯을 지나 그래픽 메모리로 옮겨집니다. GPU는 그래픽 메모리에 있는 데이터만 빠르게 쓸 수 있으므로, 화면을 그리기 전에 필요한 데이터를 미리 옮겨 두는 시간이 로딩입니다. 이 길에서 가장 좁은 곳이 전체 시간을 정합니다.

저장장치 옮길 양
저장장치 → DDR5
NVMe SSD · 약 7 GB/s—
DDR5 → 그래픽카드
PCIe 4.0 ×16 · 약 32 GB/s—
그래픽 메모리 → GPU
GDDR6X · 약 1,008 GB/s—

저장장치와 옮길 양을 고르고 ▶ 데이터 옮기기를 눌러 보세요. 막대 세 개는 같은 양을 각 구간이 혼자 옮길 때 걸리는 시간입니다.

게임용 그래픽카드는 보통 HBM 대신 GDDR 메모리를 씁니다(약 1 TB/s). AI용 GPU의 HBM(약 3.3 TB/s)은 이보다 더 넓습니다. 어느 쪽이든 그래픽카드 안쪽 길은 PCIe보다 30~100배 넓습니다. 그래서 한번 그래픽 메모리에 올린 데이터는 빠르게 쓰지만, 올리는 과정이 느립니다.

수치는 대표적인 예시입니다. CPU 코어 수, 캐시 크기와 지연 시간, GPU 코어 수는 제품마다 다릅니다. GPU 경주의 시간은 "코어 하나가 한 단계를 하는 데 CPU 0.2 ns, GPU 2 ns"로 단순화해 계산했습니다. HBM3 4스택 대역폭은 1,024비트 × 6.4 Gb/s 기준이며, HBM3E는 핀 하나가 9 Gb/s 이상으로 더 빠릅니다. 실험 4의 속도는 한 방향 최대값(PCIe 4.0 ×16 약 32 GB/s, NVMe SSD 약 7 GB/s, SATA SSD 약 0.55 GB/s, HDD 약 0.2 GB/s)이며, 실제 게임 로딩에는 압축 풀기 같은 CPU 작업 시간이 더해집니다.
